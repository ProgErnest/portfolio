# Ernest Programmer Portfolio

Static-first, bilingual portfolio built with Astro, TypeScript, and Tailwind CSS.
The project brief, architecture, design direction, content rules, roadmap, and
testing guidance are in [`docs/`](./docs/).

## Requirements

- Node.js `>=22.23.4`
- npm

## Development

```powershell
npm install
npm run dev
```

Astro prints the local development URL after it starts.

## Checks

```powershell
npm run check
npm run lint
npm run format:check
npm run build
```

React, a backend, and a database are intentionally not part of the baseline.
Add them only when a verified project requirement justifies the dependency.
