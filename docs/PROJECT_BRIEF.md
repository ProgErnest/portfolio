# Project Brief — Ernest Programmer Portfolio

## Purpose
Create a credible, distinctive professional portfolio that demonstrates the owner's software-engineering mindset through real projects, technical reasoning, and accurate professional information.

## Objectives
- Support internship and employment opportunities.
- Enable technical collaborations.
- Establish credibility through concrete project evidence.
- Provide a coherent professional online presence.

## Audience
Technical recruiters, HR professionals, software engineers, tech leads, engineering managers, and prospective clients.

## Identity and positioning
- Brand: Ernest Programmer
- Signature: EP monogram
- Positioning: Software Engineering — Systems Oriented
- Provisional tagline: Beyond Code. Building Systems.
- The owner is a software engineering student and practitioner developing toward systems architecture and technical leadership. Do not present the owner as an established software architect or senior specialist.

## Languages
- English is the default language.
- French is a complete alternative, not a partial translation.
- Prefer equivalent localized routes and preserve the current page when switching languages.

## Main pages
- Home
- About
- Projects
- Individual project case studies
- Skills
- Experience
- Contact

## Main projects
- HSVP Hub: university project implemented progressively in an internship context and defended academically. V1.0 is functional; V2.0 redesign/refactoring is in progress. Do not disclose confidential ERP scope or sensitive hospital information.
- JED: client project; implementation completed, client testing/acceptance still pending. Do not claim production validation or client acceptance.
- Auction Bids: personal project, partially functional and under reconstruction.
- Library Management: personal project; V1 is functional, with workflows and UX requiring improvement.

All four projects were developed individually. Use only verified facts and current evidence.

## Visual direction
Technical Engineering Lab × Premium Technology Studio.
- Green primary accent and blue secondary accent.
- Dark and light themes.
- Space Grotesk for headings, Inter for body/UI, JetBrains Mono for technical details (subject to actual rendering and licensing checks).
- Geometric, structured forms with moderate corner radii.
- Floating glassmorphism navigation.
- Moderate, purposeful motion, especially in the Hero.
- Avoid generic template aesthetics, excessive gradients, decorative effects without meaning, and fake technical dashboards.

## Quality goals
- Fast, accessible, responsive, maintainable, search-friendly.
- Respect reduced-motion preferences.
- Content must remain useful without JavaScript wherever practical.
- Treat project evidence and confidentiality carefully.
