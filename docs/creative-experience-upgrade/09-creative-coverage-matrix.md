# Creative Coverage Matrix

The matrix tests quality and meaning, not the number of effects. A page passes
only when its static composition, interaction, motion, responsive behavior,
accessibility, and factual boundary are all defined.

| Page | Identity | Primary experience | Meaningful interaction | Distinct motion | Responsive plan | Factual/privacy guard |
|---|---|---|---|---|---|---|
| Home | Origin/direction | EP field to project proof | Trajectory focus | Hero construction | Stack field and proof | Existing positioning only |
| About | Method/formation | Practice-to-evidence progression | Focus relationship | Line/entry reveal | Ordered vertical progression | No invented portrait/title |
| Projects | Observatory/proof | Status-aware evidence index | Native filters/focus | Group filter transition | Grid to list | Preserve exact statuses |
| HSVP Hub | Protected system | Text-first system map | Category selection | Connector draw once | Vertical ordered map | No institution/patient/real capture |
| JED | Evidence/deployment | Feature-to-screenshot story | Dialog and feature focus | Frame/dialog entrance | Full-width mobile evidence | No metrics/acceptance claim |
| Auction Bids | Reconstruction | Partial-state frame | Evidence expansion | One status change | Static frame on mobile | Repository gated; no completion claim |
| Library Management | Foundation/improvement | V1 evidence plus improvement lane | Workflow focus | Evidence/group reveal | Catalog then improvement list | Future work labeled |
| Skills | Relationships | Capability-to-context map | Category selection | Static SVG emphasis | List/details on mobile | No proficiency scores |
| Experience | Progression | Verified chronological spine | Entry focus | Marker/entry reveal | Non-pinned vertical spine | Exact dates/tasks only |
| Contact | Open endpoint | Direct closing field | Link/copy feedback | Single closing reveal | Sparse stacked channels | No backend/availability invention |
| Global shell | Continuity | Stable route instrument | Nav/theme/language | Route signal | Mobile disclosure | Preserve all existing controls |

## Balance checks

- Home is the strongest visual stage, but not the only page with a spatial
  relationship.
- Case studies receive the strongest evidence interactions.
- Skills and Experience receive relationship/progression treatment without
  pretending to be product dashboards.
- Contact is intentionally quiet but still has a composed endpoint.
- WebGL is optional for one proof and never a requirement for coverage.
- Every page has a static story before enhancement.
- Every page has an English and French equivalent.

## Review checklist

For each page, ask:

1. Can a recruiter understand the page without JavaScript?
2. Is the interaction tied to a real relationship or state?
3. Is the motion different in purpose, not merely in easing?
4. Does mobile preserve meaning rather than merely shrink geometry?
5. Does reduced motion preserve the same content and controls?
6. Is every claim supported by the project brief or current source data?
