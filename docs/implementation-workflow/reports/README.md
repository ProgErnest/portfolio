# Rapports d’implémentation

Déposer ici les rapports datés d’audits ciblés, de validation ou de mesure qui
ne sont pas déjà tenus dans un document de workflow. Chaque rapport précise son
périmètre, sa date, les commandes/outils réellement exécutés, les résultats,
les limites et les actions ouvertes.

La baseline initiale P0 est tenue dans
[`../02-technical-baseline.md`](../02-technical-baseline.md) et les contrôles
dans [`../04-progress-tracker.md`](../04-progress-tracker.md); ne pas créer de
copie divergente de ces informations.
